# BioLif

**OpenCV** *based* tool for analyzing images and videos, generated using a confocal microscope.

### Requiremets:

```
readlif (https://github.com/Arcadia-Science/readlif/tree/master)

tkinter

OpenCV-python
```


### Usage

To run use
```
biolif -f <.lif filename> <options>
```



Enjoy.
